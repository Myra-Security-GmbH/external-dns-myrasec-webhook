# Security Policy

## Reporting a Vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

This repository is a read-only public mirror; development happens internally at
Myra Security. To report a suspected security vulnerability in the Myra
ExternalDNS webhook, please use one of the following private channels:

- GitHub private security advisory:
  https://github.com/Myra-Security-GmbH/external-dns-myrasec-webhook/security/advisories/new
- Email: disclosure@myrasecurity.com

Please include a description of the issue, affected version(s)/image tags, and
steps to reproduce where possible. We aim to acknowledge reports within 3
business days and will coordinate disclosure with you.

## Supported Versions

Released container images are published to
`ghcr.io/myra-security-gmbh/external-dns-myrasec-webhook`. Security fixes are
delivered in new tagged releases; please run a currently supported tag.
